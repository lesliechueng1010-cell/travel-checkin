# 旅行足迹打卡 · 微信小程序（uni-app Vue 3）

> 名称暂用占位（`src/config.js` 里改 `BRAND.name` 一处即可全局生效）。

全国地图城市打卡小程序：去过的城市点亮打勾、未去的看攻略串行程，地图/路线/地点搜索全部使用**腾讯位置服务**，数据存**微信云开发**（本地演示模式开箱即用）。

## 一、功能总览

| 模块 | 说明 |
|---|---|
| 足迹地图 | 全国 34 个省级行政区 → 省级标记钻取到城市标记；已打卡绿色 ✓、想去橙色、未去灰色；顶部实时统计（已打卡 X 城 / 点亮占比 / 各省进度） |
| 打卡 | 手动打勾；到访地定位提示打卡；每次打卡可带日期、一句话游记、一张照片 |
| 想去清单 | 收藏未去城市；按距当前位置由近到远排序；推荐最近的未去城市 |
| 城市详情 | 必去景点、最佳季节、建议游玩天数、自驾线路、徒步线路、当地美食、**危险注意事项醒目块** |
| 串线行程 | 多城串自驾环线，总里程 + 建议天数 + 地图路线预览，可保存 |
| 导航 | 腾讯 / 高德 / 百度三选一菜单，直跳或降级均有明确反馈（见下文"导航方案说明"） |
| 美食 | 当地菜名（内置）+ 附近美食店（腾讯位置服务地点搜索，带距离） |
| 足迹海报 | Canvas 一键生成统计海报，保存相册 / 分享好友 |
| 安全角 | 高原/沙漠/冰雪/雨季/海滨/边境/城市 7 类安全知识 + 城市专项提示；页面底部固定紧急求助栏（当前定位 + 一键拨打 110/120） |
| 离线缓存 | 浏览过的城市详情自动缓存，无网可看 |

## 二、快速开始

### 1. 安装依赖并编译

```bash
npm install
npm run build:mp-weixin     # 产物输出到 dist/build/mp-weixin
```

开发期可 `npm run dev:mp-weixin`（增量编译）。

### 2. 微信开发者工具导入

1. 打开微信开发者工具 → 导入项目 → 目录选择 **`dist/build/mp-weixin`**（不是项目根目录！）。
2. AppID：先用测试号，正式发布前在 `src/manifest.json` 的 `mp-weixin.appid` 填入你的 AppID 后重新编译。
3. 编译运行后建议真机预览（地图与定位在模拟器里体验受限）。

### 3. 待填配置项（共 3 处）

| 位置 | 配置 | 说明 |
|---|---|---|
| `src/manifest.json` | `mp-weixin.appid` | 小程序 AppID |
| `src/config.js` | `tmapKey` | 腾讯位置服务 WebService API Key（距离/路线/美食店搜索用） |
| `src/config.js` | `cloudEnv` | 微信云开发环境 ID（云端存足迹用；**留空即本地演示模式，功能完整**） |

### 4. 腾讯位置服务 Key 申请

1. 前往 [lbs.qq.com](https://lbs.qq.com) 控制台 → 创建应用 → 添加 Key，类型选 **WebService API**。
2. 把 Key 填入 `src/config.js` 的 `tmapKey`。
3. 未配置 Key 的功能降级说明：里程显示**直线估算**（界面明确标注）、美食店搜索提示配置方法，其余功能不受影响。

### 5. 需要在小程序后台配置的合法域名

| 域名 | 用途 | 配置位置 |
|---|---|---|
| `https://apis.map.qq.com` | request 合法域名（地点搜索 / 路线规划） | mp.weixin.qq.com → 开发 → 开发管理 → 开发设置 → 服务器域名 |

- 微信小程序 `<map>` 组件底图由微信内置腾讯地图提供，**不需要**额外配 Key 或域名。
- 云开发调用（云函数）**不需要**配置合法域名。
- `getLocation` 属隐私接口：需在 mp.weixin.qq.com → 开发管理 → 接口设置中申请开通 **"获取当前的地理位置"**（wx.getLocation），并在"用户隐私保护指引"中声明用途（已在 `manifest.json` 配置好 `requiredPrivateInfos` 与 `permission` 描述）。

### 6. 云开发开通与初始化（可选，不配也可用）

1. 微信开发者工具 → 云开发 → 开通，得到**环境 ID**。
2. 把环境 ID 填入 `src/config.js` 的 `cloudEnv`，重新编译。
3. 右键上传 `cloudfunctions/` 下三个云函数：`login`、`tfapi`、`seed`（选"上传并部署：云端安装依赖"）。
4. 打开小程序"我的"页 → 点 **「☁️ 初始化云端攻略库」**：自动创建 `footprints`、`guides` 两个集合并把内置 43 城攻略写入云数据库。
5. 之后足迹/清单/行程自动按 **openid** 隔离存储，换设备登录自动同步。

## 三、导航方案说明（如实标注）

点「导航」弹出三选一菜单，每个选项点击后**必有成功或降级反馈**：

| 选项 | 实际方案 | 说明 |
|---|---|---|
| 腾讯地图 | **直跳** | `wx.openLocation` 直接打开微信内置腾讯地图（含目的地与路线预览，底部还可进一步拉起本机已安装的高德/百度 App）。失败时自动降级为复制方案并提示 |
| 高德地图 | **降级** | 微信小程序无官方 API 直接打开第三方地图 App；自动复制目的地名称 → 弹窗明确提示"打开高德地图 App 粘贴搜索" |
| 百度地图 | **降级** | 同上，复制地名 + 提示粘贴搜索 |

路线预览（城市详情「预览路线」、串线行程地图）在小程序内用腾讯底图 `<map>` 组件绘制；配置 tmapKey 后按真实驾车/步行路线计里程，未配置时画直线示意并标注"直线估算"。

## 四、内容红线（本项目自检过的规则）

- **不编造数字**：所有距离 / 里程 / 时长由腾讯位置服务路线规划实时计算；未配置 Key 时仅显示"直线估算"并明确标注；攻略文本中不出现任何编造的公里数 / 小时数（有自动化测试校验）。
- **安全信息**：只写通用可靠内容，所有安全板块统一附加"仅供参考，出行前请核实最新路况"。
- **无交易无支付**：不含任何收费功能。
- 地图合规：底图与位置服务全部为腾讯地图（微信内置 + 腾讯位置服务），未使用任何境外地图源。

## 六、自测方式

- 逻辑层：`node test/headless.mjs`（无依赖，22 项断言：打卡/清单/行程/缓存/红线校验等）
- 完整流程（开发者工具中）：打开地图 → 点省份 → 点城市 → 打卡 → 看攻略 → 预览路线 → 导航 → 生成海报。

## 七、已知边界（一期如实说明）

- 省直辖县级行政区（仙桃、潜江、天门、济源、石河子等）与台湾省部分县未收录在"城市"粒度中。
- 打卡照片保存于本机用户目录；云同步同步的是路径，跨设备不含图片文件本身（二期计划接云存储）。
- 攻略库覆盖 43 个重点城市，其余城市显示"内容补充中"通用模板；评分类信息不编造，需以地图详情页实时数据为准。
